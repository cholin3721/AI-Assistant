# 인하 AI 비서

Gmail · 구글 캘린더 · 구글 드라이브 · 인하공전 학교 공지를 한곳에서 다루고, **먼저 챙겨주는** 내 PC 전용 AI 비서입니다.
2026 AID 아이디어 공모전 출품작 (AI × 캠퍼스).

## 무엇을 할 수 있나요?

### 물어보면 처리해줘요
| 기능 | 예시 |

| 메일 요약·검색 | "안 읽은 메일 요약해줘" |

| 음성 | 마이크 버튼으로 말하기, 스피커 버튼으로 답변 읽어주기 (크롬·엣지) |

### 먼저 챙겨줘요 (비서 프로그램이 켜져 있는 동안)
| 기능 | 시점 |
|---|---|
| 아침 브리핑 | 매일 08:00 (변경 가능) — 오늘 수업·일정, 학사일정, 중요 메일, 답장할 메일, 다가오는 마감, 맞춤 공지 |
| 주간 회고 | 매주 금 18:00 (변경 가능) — 이번 주 정리 + 다음 주 우선순위 |
| 마감 알림 | 캘린더·할 일·학사일정(수강신청·시험 등) 마감을 D-3, D-1, 당일에 |
| 메일·공지 속 일정 찾기 | 메일 30분마다, 학교 공지 6시간마다 → **일정 후보 카드** (확인 후 「캘린더에 추가」 또는 「할 일에 저장」 — 구글 연동 없이도 마감을 챙길 수 있어요) |

### 사용 리포트
화면 왼쪽 아래 **리포트**에서 비서와의 대화 수, 먼저 챙겨준 알림, 찾아준 일정, 써준 초안, 답변 만족도(답변 아래 좋아요·아쉬워요 버튼), 아낀 시간(추정)을 볼 수 있습니다.
리포트는 메일·공지·대화 **내용이 아니라 횟수만** 셉니다. 「통계 내보내기」로 베타 테스트 결과를 익명 JSON으로 받을 수 있습니다.
웹 대화는 이 PC의 `data/` 폴더에만 남아, 새로고침해도 이어서 볼 수 있습니다.

알림은 화면의 **알림함(종 모양)**, **윈도우 알림(토스트)**, 연결한 **메신저(디스코드·텔레그램)** 로 동시에 옵니다. 메신저 DM으로 비서에게 바로 말을 걸 수도 있습니다. 디스코드 **팀 채널**을 지정하면 마감 알림·일정 후보는 그 채널로도 보내집니다. 채널 대화를 읽는 것은 기본으로 꺼져 있고, 「팀 채널 대화 요약」을 직접 켰을 때만 읽습니다.

## 실행 방법 (Windows)

0. **내려받기**: [GitHub 저장소](https://github.com/cholin3721/AI-Assistant)에서 「Code」→「Download ZIP」으로 받아 압축을 풀거나,
   `git clone https://github.com/cholin3721/AI-Assistant.git` 으로 받습니다.
1. 이 폴더의 **`run.bat`** 을 더블클릭합니다.
   - Python이 없으면 설치 페이지가 열립니다. 설치할 때 **"Add python.exe to PATH"** 를 꼭 체크하세요.
   - 처음 실행할 때만 필요한 프로그램을 설치하느라 1~2분 걸립니다.
2. 브라우저에 `http://127.0.0.1:8765` 가 열리고 **설정 마법사**가 시작됩니다. 내 정보(선택) → **Gemini API 키**(필수, 약 1분, 무료) 두 가지면 끝나고, 학교 공지·학사일정·시간표·할 일·신청서 도우미를 바로 쓸 수 있습니다.
   - **구글 연동은 첫 실행에 나오지 않습니다.** 메일·캘린더·드라이브가 필요해질 때 화면 왼쪽의 「+ 메일·캘린더도 연결하기」나, 메일 기능을 눌렀을 때 뜨는 안내에서 시작하면 됩니다 (약 5분, 처음 한 번만).
3. **수업 시간표**는 화면 왼쪽 「시간표」에서 등록합니다.
   - **포털 PDF로 한 번에**: ERP 포털 > 「개인수업시간표조회」에서 받은 PDF를 그대로 올리면 교시·강의실·교수명까지 채워집니다. AI를 거치지 않고 표를 직접 읽어서 키가 없어도 되고, 파일은 이 PC 밖으로 나가지 않습니다.
   - 캡처 사진을 올리면 AI가 읽어줍니다. 빈 칸을 눌러 직접 추가하거나(교시로 고르기), 수업을 눌러 고칠 수도 있습니다.
   - 포털 PDF에는 이름·학번이 들어 있으니 이 폴더에 두더라도 깃허브에 올라가지 않게 `.gitignore` 에 넣어 두었습니다.
4. 추가 설정은 화면 왼쪽 아래 **설정**에서 합니다.
   - **메신저 › 디스코드** (추천): 개발자 포털에서 봇을 만들고 토큰 붙여넣기 → 「내 서버에 봇 초대하기」 → 봇이 보낸 DM에 6자리 연결 코드 답장 (약 3분). 팀 채널을 고르면 마감 알림을 팀원과 공유할 수 있어요.
     - **팀 채널 대화 요약**을 쓰려면: 개발자 포털 > 내 봇 > **Bot** > **Message Content Intent** 를 켜고 저장한 뒤, 설정에서 「팀 채널 대화 요약」을 체크합니다. 봇에게 그 채널의 「메시지 기록 보기」 권한이 있어야 합니다. 켜기 전에 **팀원에게 미리 알려주세요.**
   - **메신저 › 텔레그램** (선택): BotFather에서 봇을 만들고 토큰을 붙여넣은 뒤 「텔레그램에서 연결하기」 (약 2분)
   - **자동 알림**: 브리핑 시각, 회고 요일, 관심 공지 키워드, 윈도우 알림
5. PC를 켤 때 자동으로 실행하려면 **`autostart_on.bat`** 을 한 번 실행합니다 (끄기: `autostart_off.bat`).
6. Python 없이 나눠주고 싶다면 **`build.bat`** 으로 `dist\InhaAIAssistant.exe` 를 만듭니다.

macOS/Linux에서는 `./run.sh` 를 실행합니다.

### 팀원·베타 테스터와 같이 쓸 때 (구글 연동을 1분으로)

구글 연동 7단계는 **한 명만** 하면 됩니다.

1. 한 명이 연동 가이드 1~5번을 끝내고 받은 `client_secret_….json` 파일을 팀원에게 **직접**(메신저·USB 등) 전달합니다.
2. 그 사람이 구글 클라우드의 「대상(Audience) → 테스트 사용자」에 팀원들의 Gmail 주소를 추가합니다 (최대 100명).
3. 팀원은 가이드의 **6번(파일 올리기)·7번(구글 로그인)** 만 하면 됩니다.

메일·일정은 각자 PC에서 각자 계정으로만 읽히고, 파일을 만든 사람에게 보이지 않습니다. 이 파일은 **깃허브에 올리지 마세요** (`.gitignore` 에 `client_secret*.json` 이 들어 있습니다). 테스트 모드라 7일마다 다시 로그인해야 하는 점은 같습니다.

## 보안·개인정보

- 서버는 `127.0.0.1` 에서만 열리며, **Host/Origin 검사**로 다른 웹사이트가 이 비서를 몰래 호출하지 못하게 막았습니다.
- API 키·구글 토큰·기억·할 일·시간표·대화 기록은 모두 `data/` 폴더에만 저장됩니다. 이 폴더는 `.gitignore` 에 포함돼 있으니 **절대 공유하거나 업로드하지 마세요**.
- **AI 처리는 Google Gemini에서 합니다.** 답을 만들 때 질문과 읽어 온 내용(공지, 연결했다면 메일·일정·문서 일부)이 Gemini API로 전송됩니다. 이 프로그램을 만든 사람이나 그 밖의 서버로는 보내지 않습니다.
- **무료 Gemini 키 주의**: [Gemini API 약관](https://ai.google.dev/gemini-api/terms)상 무료 키로 보낸 내용은 구글이 서비스 개선에 쓸 수 있고 사람이 검토할 수도 있습니다. 민감한 메일까지 맡기려면 결제를 등록한 유료 키를 쓰세요(유료는 서비스 개선에 쓰지 않는다고 안내돼 있습니다).
- 메일은 **초안만** 만들고 직접 보내지 않습니다. 일정 등록은 사용자가 요청했을 때만 합니다.
- 메일·공지에서 찾은 일정은 바로 등록하지 않고 **후보 카드**로만 보여줍니다(스팸 메일이 캘린더를 조작하거나 AI가 날짜를 잘못 읽는 경우 대비).
- 디스코드·텔레그램 봇은 연결 코드로 등록한 **주인에게만** 응답합니다. 디스코드는 기본적으로 DM만 처리하고 서버 채널 메시지는 읽지 않습니다. 「팀 채널 대화 요약」을 켰을 때만, 지정한 **팀 채널 한 곳**의 최근 대화를 요청받은 순간에 읽어 요약하며 따로 저장하지 않습니다.
- 비밀번호·계좌번호 같은 민감정보는 기억하지 않습니다.
- 메일·공지·첨부 본문과 팀 채널 대화 안의 지시문은 데이터로만 취급하도록 AI에 지시했습니다(프롬프트 인젝션 방지).

## 알아둘 점

- 구글 연동 앱은 '테스트 모드'라 **7일마다 다시 로그인**해야 합니다. 설정 > 구글에서 「구글 로그인」만 누르면 됩니다.
  7일 만료를 없애려면 구글 클라우드 **인증 플랫폼 → 게시 상태**에서 앱을 **프로덕션**으로 바꾸세요. (미검증 경고 화면은 남을 수 있습니다.)
- 학교 계정(@inhatc.ac.kr)은 관리자 설정 때문에 AI Studio나 Cloud Console이 막혀 있을 수 있습니다. 이럴 때는 개인 Gmail 계정을 사용하세요.
- **구글 연동은 선택**입니다. 공지·학사일정·할 일·시간표·신청서 도우미는 키만 넣으면 바로 됩니다. 구글이 없을 때는 화면의 「바로 해보기」 버튼도 구글 없이 되는 것만 보입니다.
- 빈 시간 찾기에서 **종일 일정(마감일 등)은 시간을 막지 않는 것**으로 봅니다. 취소·거절한 일정과 '한가함'으로 표시한 일정도 뺍니다.
- 프로그램을 껐다 켜도 AI가 **직전 대화(최근 6번 주고받은 내용)** 를 이어받습니다.
- 자동 알림은 비서 프로그램이 켜져 있을 때만 동작합니다. PC가 꺼져 있던 시간의 아침 브리핑은 켜진 뒤 그날 안에 한 번 보냅니다. 브리핑 시각이 밤이어도 자정을 넘겨 10시간 안이면 보냅니다.
- 학교 공지·학사일정은 각각 10분 / 6시간 캐시되므로 홈페이지에 부담을 주지 않습니다.
- 암호가 걸린 한글 파일은 읽지 못합니다. 스캔 이미지 PDF는 Gemini로 글자를 읽습니다.
- 대화가 20턴을 넘으면 요약을 남기고 새 세션으로 이어갑니다. 새로고침해도 최근 대화는 복원됩니다.

## 구조

```
app/
  main.py             FastAPI 서버 (API + 화면, SSE 스트리밍, Host/Origin 검사)
  agent.py            Gemini 에이전트 (도구 자동 호출, 진행 이벤트, 세션 요약)
  scheduler.py        아침 브리핑·주간 회고·마감 알림·자동 일정 찾기
  schedule_finder.py  메일·공지 → 일정 후보 추출 (구조화 출력, 중복 제거)
  followups.py        답장 안 한 메일 / 회신 대기 메일
  attachments.py      hwp·hwpx·pdf·docx·이미지 OCR 텍스트 추출
  discord_bot.py      디스코드 DM 알림 + DM 대화 + 팀 채널 보내기·(선택) 대화 읽기
  telegram_bot.py     텔레그램 알림 + 폰에서 대화
  desktop.py          윈도우 토스트 알림
  chats.py            웹 대화 기록 저장·복원
  memory.py todos.py timetable.py   기억 · 할 일 · 시간표/빈 시간
  portal_timetable.py 포털 「개인수업시간표조회」 PDF 읽기 (AI 없이 좌표로)
  forms.py            신청서·보고서 작성 도우미
  stats.py            사용 통계·답변 평가
  notify.py store.py  알림함 · 저장소
  google_auth.py      구글 OAuth
  tools/              gmail, gcalendar, drive, notices, schedule, academic, teamchat
  static/             웹 화면
tests/                단위 테스트 (네트워크 없이)
data/                 키·토큰·기록 (자동 생성, 공유 금지)
run.bat / run.sh      원클릭 실행
build.bat             PyInstaller 실행 파일 만들기
autostart_on/off.bat  윈도우 시작 시 자동 실행 켜기/끄기
```

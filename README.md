# 인하 AI 비서

Gmail · 구글 캘린더 · 구글 드라이브 · 인하공전 학교 공지를 한곳에서 다루고, **먼저 챙겨주는** 내 PC 전용 AI 비서입니다.
2026 AID 아이디어 공모전 출품작 (AI × 캠퍼스).

## 무엇을 할 수 있나요?

### 물어보면 처리해줘요
| 기능 | 예시 |
|---|---|
| 메일 요약·검색 | "안 읽은 메일 요약해줘" |
| 답장 초안 | "교수님 메일에 답장 초안 써줘" → Gmail 임시보관함에 저장 (자동 발송 없음) |
| 답장 챙기기 | "내가 답장 안 한 메일 있어?", "보냈는데 답 없는 메일 찾아줘" → 리마인드 초안까지 |

| 음성 | 마이크 버튼으로 말하기, 스피커 버튼으로 답변 읽어주기 (크롬·엣지) |

### 먼저 챙겨줘요 (비서 프로그램이 켜져 있는 동안)
| 기능 | 시점 |
|---|---|
| 아침 브리핑 | 매일 08:00 (변경 가능) — 오늘 수업·일정, 중요 메일, 답장할 메일, 다가오는 마감, 맞춤 공지 |
| 주간 회고 | 매주 금 18:00 (변경 가능) — 이번 주 정리 + 다음 주 우선순위 |
| 마감 알림 | 캘린더 마감·할 일 마감을 D-3, D-1, 당일에 |
| 메일·공지 속 일정 찾기 | 메일 30분마다, 학교 공지 6시간마다 → **일정 후보 카드** (확인 후 「캘린더에 추가」) |

### 사용 리포트
화면 왼쪽 아래 **리포트**에서 비서와의 대화 수, 먼저 챙겨준 알림, 찾아준 일정, 써준 초안, 답변 만족도(답변 아래 좋아요·아쉬워요 버튼), 아낀 시간(추정)을 볼 수 있습니다.
메일·공지·대화 내용은 저장하지 않고 횟수만 세며, 「통계 내보내기」로 베타 테스트 결과를 익명 JSON으로 받을 수 있습니다.

알림은 화면의 **알림함(종 모양)** 과 연결한 **메신저(디스코드·텔레그램)** 로 동시에 옵니다. 메신저 DM으로 비서에게 바로 말을 걸 수도 있습니다.

## 실행 방법 (Windows)

0. **내려받기**: [GitHub 저장소](https://github.com/cholin3721/AI-Assistant)에서 「Code」→「Download ZIP」으로 받아 압축을 풀거나,
   `git clone https://github.com/cholin3721/AI-Assistant.git` 으로 받습니다.
1. 이 폴더의 **`run.bat`** 을 더블클릭합니다.
   - Python이 없으면 설치 페이지가 열립니다. 설치할 때 **"Add python.exe to PATH"** 를 꼭 체크하세요.
   - 처음 실행할 때만 필요한 프로그램을 설치하느라 1~2분 걸립니다.
2. 브라우저에 `http://127.0.0.1:8765` 가 열리고 **설정 마법사**가 시작됩니다.
   - **Gemini API 키** (필수, 약 1분, 무료)
   - **구글 연동** (선택, 약 5분, 처음 한 번만)
3. 추가 설정은 화면 왼쪽 아래 **설정**에서 합니다.
   - **메신저 › 디스코드** (추천): 개발자 포털에서 봇을 만들고 토큰 붙여넣기 → 「내 서버에 봇 초대하기」 → 봇이 보낸 DM에 6자리 연결 코드 답장 (약 3분)
   - **메신저 › 텔레그램** (선택): BotFather에서 봇을 만들고 토큰을 붙여넣은 뒤 「텔레그램에서 연결하기」 (약 2분)
   - **시간표**: 시간표 캡처 이미지를 올리면 AI가 읽어서 채워줍니다
   - **자동 알림**: 브리핑 시각, 회고 요일 등
4. PC를 켤 때 자동으로 실행하려면 **`autostart_on.bat`** 을 한 번 실행합니다 (끄기: `autostart_off.bat`).

macOS/Linux에서는 `./run.sh` 를 실행합니다.

## 보안·개인정보

- 서버는 `127.0.0.1` 에서만 열리므로 **내 PC 밖에서는 접속할 수 없습니다**.
- API 키·구글 토큰·기억·할 일·시간표는 모두 `data/` 폴더에만 저장됩니다. 이 폴더는 `.gitignore` 에 포함돼 있으니 **절대 공유하거나 업로드하지 마세요**.
- 메일은 **초안만** 만들고 직접 보내지 않습니다. 일정 등록은 사용자가 요청했을 때만 합니다.
- 메일·공지에서 찾은 일정은 바로 등록하지 않고 **후보 카드**로만 보여줍니다(스팸 메일이 캘린더를 조작하거나 AI가 날짜를 잘못 읽는 경우 대비).
- 디스코드·텔레그램 봇은 연결 코드로 등록한 **주인에게만** 응답합니다. 디스코드는 DM만 처리하고 서버 채널 메시지는 읽지 않습니다.
- 비밀번호·계좌번호 같은 민감정보는 기억하지 않습니다.
- 메일·공지·첨부 본문 안의 지시문은 데이터로만 취급하도록 AI에 지시했습니다(프롬프트 인젝션 방지).

## 알아둘 점

- 구글 연동 앱은 '테스트 모드'라 **7일마다 다시 로그인**해야 합니다. 설정 > 구글에서 「구글 로그인」만 누르면 됩니다.
- 학교 계정(@inhatc.ac.kr)은 관리자 설정 때문에 AI Studio나 Cloud Console이 막혀 있을 수 있습니다. 이럴 때는 개인 Gmail 계정을 사용하세요.
- 자동 알림은 비서 프로그램이 켜져 있을 때만 동작합니다. PC가 꺼져 있던 시간의 아침 브리핑은 켜진 뒤 그날 안에 한 번 보냅니다.
- 학교 공지는 10분간 캐시되므로 홈페이지에 부담을 주지 않습니다.
- 암호가 걸린 한글 파일, 스캔 이미지로 된 PDF는 읽지 못합니다.

## 구조

```
app/
  main.py             FastAPI 서버 (API + 화면)
  agent.py            Gemini 에이전트 (도구 23개 자동 호출, 시스템 프롬프트)
  scheduler.py        아침 브리핑·주간 회고·마감 알림·자동 일정 찾기
  schedule_finder.py  메일·공지 → 일정 후보 추출 (구조화 출력, 중복 제거)
  followups.py        답장 안 한 메일 / 회신 대기 메일
  attachments.py      hwp·hwpx·pdf·docx 텍스트 추출
  discord_bot.py      디스코드 DM 알림 + DM으로 대화
  telegram_bot.py     텔레그램 알림 + 폰에서 대화
  memory.py todos.py timetable.py   기억 · 할 일 · 시간표/빈 시간
  forms.py            신청서·보고서 작성 도우미 (항목 추출 → 초안 → 워드 저장)
  stats.py            사용 통계·답변 평가 (내용 없이 횟수만)
  notify.py store.py  알림함 · 저장소
  google_auth.py      구글 OAuth (데스크톱 앱 방식)
  tools/              gmail, gcalendar, drive, notices, schedule
  static/             웹 화면
data/                 키·토큰·기록 (자동 생성, 공유 금지)
run.bat / run.sh      원클릭 실행
autostart_on/off.bat  윈도우 시작 시 자동 실행 켜기/끄기
```

  • 학교 공지 내 학과·관심사에 맞는 공모전·장학·특강 추천, 한글(hwp) 첨부까지 읽기
  • 신청 준비 신청 체크리스트, 신청서·보고서 초안
  • 학사일정·시간표·할 일 수강신청·시험 날짜, 포털 시간표 PDF 등록, 빈 시간 찾기
  • 먼저 챙기기 아침 브리핑, 마감 D-3·D-1 알림 — 디스코드로도
  • 나를 기억 지도교수·팀원 연락처처럼 말해 둔 것
  • 구글을 연결하면 메일 요약·답장 초안(자동 발송 없음), 캘린더, 드라이브까지
내 정보는 어디로 가나요? 키·구글 로그인 정보·대화 기록·시간표는 이 PC의 data 폴더에만 저장돼요. 다만 답을 만들려면 질문과 읽어 온 내용(공지, 연결했다면 메일·일정)이 Google Gemini로 전송돼요. 비서를 만든 사람이나 그 밖의 서버로는 보내지 않아요. 디스코드·텔레그램을 연결하면 알림이 그 메신저로도 가요.

Gmail · 캘린더 · 드라이브 연결 약 5분 · 처음 한 번만

나만 쓰는 '구글 연결 통로'를 만드는 과정이에요. 안 해도 학교 공지·학사일정·시간표·신청서 도우미는 그대로 쓸 수 있어요. 순서대로 따라 하고 각 단계의 체크를 눌러주세요. 개인 Gmail 계정을 추천해요.

팀원에게 열쇠 파일을 받았나요? client_secret_….json 파일을 받았다면 1~5번은 건너뛰고 6번부터 하면 돼요. 단, 파일을 만든 팀원이 내 Gmail 주소를 4번(테스트 사용자)에 추가해 줘야 로그인이 돼요.
  1. 프로젝트 만들기 — 이름은 AI-Assistant처럼 아무거나 넣고 「만들기」. 프로젝트 만들기 열기 ↗
  2. API 3개 켜기 — 방금 만든 프로젝트가 선택돼 있는지 확인하고 「다음」→「사용 설정」. Gmail·Calendar·Drive가 한 번에 켜져요. API 한 번에 켜기 ↗
  3. 앱 정보 등록 — 「시작하기」를 누르고 앱 이름(예: 내 AI 비서), 지원 이메일(내 메일) 입력 → 대상은 「외부」 → 연락처에 내 메일 → 정책 동의 → 「만들기」. Google 인증 플랫폼 열기 ↗
  4. 나를 테스트 사용자로 추가 — 「테스트 사용자」 아래 「+ Add users」→ 로그인할 내 Gmail 주소 입력 → 저장. 이걸 빠뜨리면 로그인 때 ‘액세스 차단’이 떠요. 대상(Audience) 열기 ↗
  5. 열쇠 파일 받기 — 「클라이언트 만들기」→ 애플리케이션 유형 「데스크톱 앱」 → 「만들기」→ 팝업에서 「JSON 다운로드」. 클라이언트 화면 열기 ↗
  6. 받은 JSON 파일을 여기에 올리기
  7. 구글 로그인 — 버튼을 누르면 새 브라우저 창이 열려요. 계정 선택 → “Google에서 확인하지 않은 앱” 화면이 나오면 「고급」→「(안전하지 않음)으로 이동」을 눌러요. 직접 만든 앱이라 괜찮아요. 권한을 모두 체크하고 「계속」.
잘 안 되나요?
  • “액세스 차단됨: 앱이 테스트 중” → 4번(테스트 사용자 추가)에서 로그인한 계정과 같은 주소를 넣었는지 확인하세요.
  • “웹 애플리케이션 유형” 오류 → 5번에서 유형을 데스크톱 앱으로 다시 만들어주세요.
  • “API has not been used / disabled” → 2번 API 켜기를 같은 프로젝트에서 했는지 확인하세요.
  • 테스트 모드 앱은 7일마다 로그인이 만료돼요. 그때는 설정에서 「구글 로그인」만 다시 누르면 돼요. 구글 클라우드에서 앱을 프로덕션(게시)으로 바꾸면 7일 만료가 사라집니다. (미검증 경고 화면은 한 번 더 뜹니다)
